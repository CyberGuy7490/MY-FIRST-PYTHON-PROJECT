#  Python Poem

A simple Python project that displays a poem in the terminal using Python's `print()` function.

##  About

This project was created as a beginner Python exercise to practice basic programming concepts such as:

* `print()` function
* Multi-line strings
* Python syntax
* Basic program structure

##  Code

```python
print("""
        MY First Python POEM

Roses are red,
Violets are blue,
Python is awesome,
so do you!
""")
```

## How to Run

Make sure Python is installed on your computer.

Clone this repository:

```bash
git clone https://github.com/your-username/python-poem.git
```

Navigate to the project folder:

```bash
cd python-poem
```

Run the program:

```bash
python poem.py
```
